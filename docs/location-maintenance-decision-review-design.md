# 校园地点维护决策回看设计

## 为什么继续做

上一轮的 `CampusLocationMaintenanceDecision` 让维护队列能区分「待核对」和「已复核」，
也能说清已复核后的三类结果。当前看板还剩两个运营问题：

1. 当前这批信号是最近才有人看，还是一直靠几个月前的旧决策撑着复核率；
2. 标成「暂缓处理」的地点有没有长期留在队列里，最后变成没人再看的老账。

这两个问题不能靠把当前快照再读一遍来回答，需要把匹配当前信号的决策按时间拆开，并单独
看暂缓项最后一次被确认的时间。

## 先承认数据不能回答什么

系统没有保存维护队列的历史快照，也没有决策编辑审计表。当前决策表对同一地点、同一组信
号只有一行：

- `created_at` 能说明这组信号第一次被留下决策的时间；
- `updated_at` 能说明这条决策最后一次被改写的时间；
- 它不能还原每天当时的队列总数，也不能还原每一次编辑前的结论。

因此本模块不计算「某周期处理率」，不给升降方向，不生成处理速度评分。它只报告当前队列
里的决策是什么时候第一次沉淀下来的，以及暂缓项已经多久没有更新。

## 目标

- 延续维护队列的信号指纹口径，只统计匹配当前信号的决策；
- 按本地午夜把首次决策拆成本周期、上一等长周期、更早三段；
- 报当前快照的复核比例，但不把比例变化伪装成跨周期趋势；
- 单独列出仍为「暂缓处理」的当前队列行，按最后更新时间从久到近排序；
- 输出暂缓项的最后更新间隔，用于观察堆积，不设定服务级别、不自动催办；
- 继续只读，不改决策、不改地点、不触发通知；
- 看板与导出不输出复核人、判断说明或其他个人化内容。

## 时间口径

- 本周期与上一周期使用运营看板跨周期面板共用的本地午夜边界；
- 本周期可能包含未结束的当天，页面必须保留这个提醒；
- 首次决策归属按 `created_at` 落入的周期切分；
- 决策停留按 `created_at` 到当前时刻的完整本地日期数计算；
- 暂缓最后更新间隔按 `updated_at` 到当前时刻的完整本地日期数计算；
- `updated_at` 只代表最后一次编辑，不能数出编辑次数，也不能知道编辑前结论；
- 未来时间戳按 0 天处理，避免异常数据把均值或区间拉成负数。

## 输出结构

```python
{
    "has_data": bool,
    "days": int,
    "current_period_start": datetime,
    "previous_period_start": datetime,
    "summary": {
        "queued_total": int,
        "reviewed_total": int,
        "reviewed_share": float | None,
        "first_decision_current_total": int,
        "first_decision_previous_total": int,
        "first_decision_earlier_total": int,
        "deferred_total": int,
    },
    "first_decision_rows": [...],
    "outcome_age_rows": [...],
    "deferred_rows": [...],
    "deferred_row_limit": 10,
    "deferred_row_hidden_total": int,
}
```

- `first_decision_rows`：当前匹配决策按首次留痕时间分到本周期、上一周期、更早；
- `outcome_age_rows`：三类结果按首次决策停留区间拆分，用来观察不同结论的年龄结构；
- `deferred_rows`：最多 10 条当前仍暂缓的地点，输出地点、主优先级、信号、结果、最后
  更新时间和停留天数；
- 截断只影响清单，不影响汇总；
- 空队列和有队列但没有决策都返回固定结构，不报错。

## 边界

- 不创建新表，不加字段，不加迁移；
- 不改 `CampusLocationMaintenanceDecision`；
- 不把旧决策当作信号消失，也不把暂缓项从队列隐藏；
- 不自动催办、不发通知、不生成任务；
- 不给「暂缓多久」设定阈值或好坏结论；
- 不输出复核人和自由备注；
- 队列与回看都保持只读。

## 测试计划

- 空平台与无决策队列保持固定结构；
- 信号指纹不匹配的旧决策不进入回看；
- 首次决策按本地午夜归入本周期、上一周期或更早；
- 复核比例的分母是当前队列总数；
- 三类结果的停留区间固定且互斥；
- 暂缓清单按最后更新时间从久到近排序，最多 10 行；
- 未来时间戳不产生负天数；
- 构建过程不修改地点与决策；
- 运营页面与 CSV 导出包含同名面板和相同口径说明。
