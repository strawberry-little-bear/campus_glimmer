## 维护约定

- 截图应反映当前主导航、品牌色和核心页面结构；
- 不出现真实姓名、邮箱、手机号、私信内容或其他个人数据；
- 优先使用 `python init_data.py` 准备稳定的演示数据；
- 截图尺寸保持一致，当前基准为 `1424 × 969`；
- 替换截图后同步检查根 README 中的说明文字是否仍然准确；
- 品牌图标位于 [`../assets/brand-mark.svg`](../assets/brand-mark.svg)。
